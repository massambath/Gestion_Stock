# 🧮 Application de gestion de stock

Une mini-application Python pour gérer le stock d’une boutique et générer des factures simples.

## 📦 Fonctionnalités
- Ajouter et afficher les produits
- Enregistrer une vente
- Met à jour le stock automatiquement
- Génère une facture après chaque vente
- Base de données SQLite intégrée
- Possibilité d'ajouter données via csv

## 🚀 Lancer le projet
```bashgit 
python app.py
